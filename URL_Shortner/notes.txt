URL Endpoints

Admin
get "/user" - Admin user able to retrieve all user details present
get "/url"  - Admin user able to retrieve all url details present
delete "/urls/{alias}" = Admin only can delete the URL present in DB

User
post "/" - Create New User
get "/me" - Get the Logged in User details
patch "/upgrade" - Upgrade User Membership

URL - Only User can create URLs not Admin
post "/" - Create Short_url
get "/" - User get all their registered URLs
get "/{alias}" - Get specific URL filter by Alias
patch "/upgrade/{alias}" - Premium user can upgrade the expiry date and alias, for basic user, url is marked as expired and not be accessible.

Stats
get "/{alias}" - Get Url Stats by Alias

Redirect
get "/{alias}" - Get URL for Redirection
