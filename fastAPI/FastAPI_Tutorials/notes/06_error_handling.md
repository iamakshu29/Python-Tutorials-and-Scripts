# FastAPI — Error Handling (The 4-Layer Pattern)

<!-- Stack: FastAPI 0.115 | Python 3.12 -->

---

## The Core Decision (Two Types of Errors)

**In my own words:**
There are only two questions to ask when you hit an error scenario:

> "Is my code waiting for a response from somewhere else?"

```
YES → try/except → raise HTTPException
NO  → plain if/raise HTTPException
```

| Scenario | Approach |
|---|---|
| "Is this ID negative?" | `if id <= 0: raise HTTPException(...)` |
| "Does the user own this?" | `if item.owner != user_id: raise HTTPException(...)` |
| DB query | `try: db.execute(...) except SQLAlchemyError: raise HTTPException(...)` |
| External API call | `try: requests.get(...) except RequestException: raise HTTPException(...)` |
| File read | `try: open(...) except FileNotFoundError: raise HTTPException(...)` |

---

## The 4 Layers

```
Layer 1 — Input validation   →  Pydantic does this automatically (422 on fail)
Layer 2 — Business logic     →  plain if/raise HTTPException
Layer 3 — I/O operations     →  try/except → raise HTTPException
Layer 4 — Unhandled fallback →  FastAPI returns 500 (you control nothing here)
```

## Logging Rule (Security)

**In my own words:**
Log the real error on the server. Send a generic message to the client. Never expose stack traces, DB errors, or internal paths in HTTP responses.

```python
# Generated by GitHub Copilot
import logging
logger = logging.getLogger(__name__)

try:
    result = db.execute(select(User).where(User.id == user_id)).scalar_one_or_none()
except SQLAlchemyError as e:
    logger.error(f"DB error fetching user {user_id}: {e}")   # server log — for you
    raise HTTPException(status_code=500, detail="Database error occurred")  # client — generic
```

## Full Route Pattern

```python
# Generated by GitHub Copilot
from fastapi import APIRouter, HTTPException, Path
from sqlalchemy.exc import SQLAlchemyError
from starlette import status

@router.get("/{todo_id}", status_code=status.HTTP_200_OK)
async def get_todo(
    user: user_dependency,
    db: DbDependency,
    todo_id: int = Path(gt=0)   # Layer 1: Path validates todo_id > 0 automatically
):
    # Layer 2: Business logic check (no I/O, plain if)
    if user is None:
        raise HTTPException(status_code=401, detail="Authentication Failed")

    # Layer 3: I/O — wrap DB calls in try/except
    try:
        todo = db.query(Todos).filter(
            Todos.id == todo_id,
            Todos.owner == user.get("user_id")   # prevents accessing another user's data
        ).first()
    except SQLAlchemyError as e:
        raise HTTPException(status_code=500, detail="Database error occurred")

    # Layer 2 again: business logic after I/O
    if todo is None:
        raise HTTPException(status_code=404, detail="Todo not found")

    return todo
```

## Common HTTP Status Codes

| Code | When to use |
|---|---|
| `200 OK` | GET success (default) |
| `201 Created` | POST that creates a resource |
| `204 No Content` | DELETE success (no body returned) |
| `400 Bad Request` | Client sent bad data that Pydantic didn't catch |
| `401 Unauthorized` | No valid token / not authenticated |
| `403 Forbidden` | Authenticated but not allowed (wrong role) |
| `404 Not Found` | Resource doesn't exist |
| `422 Unprocessable Entity` | FastAPI/Pydantic validation failure (automatic) |
| `500 Internal Server Error` | Your code broke — use for unexpected DB/IO errors |

## `Path` and `Query` Validation (Layer 1 for URL params)

**In my own words:**
`Path()` and `Query()` add validation rules to URL path and query parameters. FastAPI enforces them automatically — like `Field()` for Pydantic, but for route params.

```python
# Generated by GitHub Copilot
from fastapi import Path, Query

@router.get("/{item_id}")
async def get_item(
    item_id: int = Path(gt=0, description="Must be a positive integer"),
    search: str = Query(default=None, min_length=2, max_length=50)
):
    ...
```

**Gotchas:**
- `Path(gt=0)` fails before the route body runs — no DB hit needed.
- `Query(default=None)` makes the query param optional. Without `default`, it's required.
